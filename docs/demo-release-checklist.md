# 演示版收口清单

目标：老板打开页面后，可以稳定演示“上传素材 -> 生成成片 -> 查看 -> 标记可交付 -> 导出交付包”。

## 演示前必须确认

- 后端已启动：`http://127.0.0.1:8000/api/health` 返回 `ok`
- `.env` 已配置 `ALIYUN_DASHSCOPE_API_KEY`
- 正式前端可打开：`http://127.0.0.1:8000/`
- 测试台可打开：`http://127.0.0.1:8000/test`
- 素材库里至少保留 2 组模特、2 组婚纱
- 任务列表里保留 3-5 张效果稳定的已完成成片
- 至少 1 张成片已标记为“可交付”
- “导出交付包”按钮可以下载 zip

## 演示素材建议

- 模特：正面全身、光线干净、脸部清晰
- 婚纱：拖地款、单件服装、背景简单
- 场景：优先使用影棚、花园、教堂
- 动作：演示版优先保持原姿势，不在老板演示时冒险测试大动作

## 演示顺序

1. 打开正式前端，说明这是“婚纱 AI 交付台”。
2. 左侧选择模特原图和婚纱款式。
3. 中间选择场景，点击开始生成。
4. 右侧展示历史任务，打开一张已完成成片。
5. 在预览弹窗里下载原图、标记可交付。
6. 右侧点击导出交付包。
7. 打开测试台只作为技术调试入口，不作为老板主界面。

## 不建议现场演示

- 实验动作：坐姿、回眸、台阶、手扶裙摆
- 2K 大图批量生成
- 大量连续删除历史任务
- 现场修改 API Key 或后端配置

## 发布前验证命令

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend\tests -v
cd frontend
npm run build
cd ..
```

验证通过后再提交 Git。
