# 质量评分规则

评分范围：1-5 分。

## 评分维度

### 人脸

- 5：高度像本人，肤色、五官、表情自然
- 4：基本像本人，小细节可接受
- 3：能看出相似，但有轻微换脸感
- 2：不像本人或明显贴脸
- 1：严重变脸、脸部崩坏

### 款式

- 5：婚纱轮廓、长度、袖型、材质都还原
- 4：主款式正确，细节略有变化
- 3：大体是婚纱，但裙型或材质明显偏移
- 2：婚纱变短、变成另一款
- 1：服装完全错误或出现两条裙子

### 动作

- 5：动作自然，手脚和裙摆都合理
- 4：动作基本正确，有轻微不自然
- 3：动作部分生效，但不影响演示
- 2：动作不稳定，手脚或裙摆有明显问题
- 1：多手、多腿、断肢、严重变形

### 背景

- 5：背景真实、光线融合、主体清晰
- 4：背景正确，融合略有瑕疵
- 3：背景可用，但光线或透视一般
- 2：背景不听指令或遮挡主体
- 1：背景严重错误、主体被破坏

## 自动通过规则

前端保存评分时，后端会自动判定是否可作为演示候选：

- 人脸 >= 4
- 款式 >= 4
- 动作 >= 3
- 背景 >= 3
- 总体 >= 4

总体分如果不手动传入，后端会按四项平均值四舍五入。

## 使用建议

- 老板演示只用“可演示”的图。
- 动作测试可以保留“待优化”的图，但备注必须写清楚问题。
- 每次改提示词或生成链路，都用同一批测试集重新评分。
